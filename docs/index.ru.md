Container Files это файловый менеджер для контейнеров Docker и Podman. Он работает по SSH-подключению, которое у Termix уже есть к хосту, и ничего не устанавливает в контейнер.

## Включение

1. Установите Container Files на вкладке Plugins.
2. Откройте вкладку Container Files на хосте с включённым SSH.
3. Выберите контейнер. Он откроется в корневой папке.

Для работы нужно право Use Container Files, оно по умолчанию есть у администраторов и пользователей.

## Использование

- Двойной щелчок открывает папку. Правая кнопка мыши открывает действия: новый файл или папка, переименование, копирование, вырезание, вставка, удаление, права, символическая ссылка, упаковка, распаковка.
- Перетащите файлы с компьютера в окно, чтобы загрузить их. Пункт Download в меню сохраняет файлы и папки.
- Кнопка с плюсом добавляет ещё контейнеры. Панели делят окно плиткой; перетащите панель за заголовок, чтобы переместить или поменять её местами с другой.
- Кнопка Mounts показывает монтирования контейнера (тип, источник, чтение-запись или только чтение). Папки монтирований отмечены буквами RW или RO на значке.
- Чтобы добавить файлы в архив, выберите в меню Add to archive или перетащите файлы на архив (или в его открытое окно). Работает для zip, 7z, tar, tar.gz, tar.bz2, tar.xz и tar.zst; в контейнере нужны соответствующие GNU tar, zip, 7z, gzip, bzip2, xz или zstd, а если их нет, причина показывается при перетаскивании.
- Чтобы удалить записи из архива, выделите их в его открытом окне и выберите Delete (или нажмите клавишу Delete), затем подтвердите. Работает для тех же форматов, что и добавление, для tar-архивов нужен GNU tar. Архивы rar можно только просматривать и распаковывать, одиночные файлы .gz, .bz2, .xz и .zst только распаковывать. Если программы нет, сообщение называет её, например «7z is not installed in this container».
- Ctrl/Cmd+C, X и V копируют, вырезают и вставляют между панелями. Файлы, скопированные в Проводнике Windows или Finder, вставляются по Ctrl/Cmd+V (только файлы, не папки).
- В диалогах Enter нажимает выделенную кнопку, стрелки переключают кнопки, Escape закрывает окно.
- В Termix Desktop панель компьютера показывает ваши файлы. Файлы можно перетаскивать между ней и контейнером в обе стороны либо копировать, вырезать и вставлять через меню и Ctrl/Cmd+C, X и V (между двумя локальными папками нельзя). В Windows Copy в панели контейнера также кладёт файлы в буфер обмена Windows (до 512 МБ), и Проводник может их вставить. Хосты, настроенные на подключение через сервер, работают и в десктопном приложении. Кнопка на панели инструментов показывает папку в системном проводнике.
- В остановленных контейнерах и контейнерах без оболочки доступны только просмотр, чтение, загрузка и скачивание. Для отключённых действий указана причина.

Каждый пользователь может задать в настройках, сколько передач выполняется одновременно (от 1 до 4).

## Что разрешено плагину

| Способность                                    | Зачем                                                                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `hosts:read`, `credentials:use`, `ssh:connect` | Подключиться к хосту с сохранённым логином и выполнять там `docker` или `podman`. Плагин не видит пароль или ключ. |
| `network:serve`                                | Собственные маршруты для списков, передач и прогресса.                                                             |
| `ui:surface`                                   | Вкладка и настройки.                                                                                               |
| `desktop:local`                                | Только Termix Desktop: показ файлов компьютера, чтение и запись перетаскиваемых файлов.                            |

Плагин сам не выполняет сетевых запросов и не отправляет телеметрию. Локальных файлов он касается только по вашему действию.
