Container Files это файловый менеджер для контейнеров Docker и Podman. Он работает по SSH-подключению, которое у Termix уже есть к хосту, и ничего не устанавливает в контейнер.

## Включение

1. Установите Container Files на вкладке Plugins.
2. Откройте вкладку Container Files на хосте с включённым SSH.
3. Выберите контейнер. Он откроется в корневой папке.

Для работы нужно право Use Container Files, оно по умолчанию есть у администраторов и пользователей.

## Использование

- Двойной щелчок открывает папку. Правая кнопка мыши открывает действия: новый файл или папка, переименование, копирование, вырезание, вставка, удаление, права, символическая ссылка, упаковка, распаковка.
- Перетащите файлы с компьютера в окно, чтобы загрузить их. Пункт Download в меню сохраняет файлы и папки.
- Кнопка с плюсом добавляет ещё контейнеры. Панели делят окно плиткой; перетащите панель за заголовок, чтобы переместить или поменять её местами с другой.
- В Termix Desktop панель компьютера показывает ваши файлы. Файлы можно перетаскивать между ней и контейнером в обе стороны. Кнопка на панели инструментов показывает папку в системном проводнике.
- В остановленных контейнерах и контейнерах без оболочки доступны только просмотр, чтение, загрузка и скачивание. Для отключённых действий указана причина.

Каждый пользователь может задать в настройках, сколько передач выполняется одновременно (от 1 до 4).

## Что разрешено плагину

| Способность | Зачем |
| --- | --- |
| `hosts:read`, `credentials:use`, `ssh:connect` | Подключиться к хосту с сохранённым логином и выполнять там `docker` или `podman`. Плагин не видит пароль или ключ. |
| `network:serve` | Собственные маршруты для списков, передач и прогресса. |
| `ui:surface` | Вкладка и настройки. |
| `desktop:local` | Только Termix Desktop: показ файлов компьютера, чтение и запись перетаскиваемых файлов. |

Плагин сам не выполняет сетевых запросов и не отправляет телеметрию. Локальных файлов он касается только по вашему действию.
