# Container Files

[English](README.md) · **Русский**

Плагин [Termix](https://github.com/Termix-SSH/Termix) для просмотра файлов внутри контейнеров Docker и Podman и управления ими по тому SSH-подключению, которое вы уже используете для хоста. В контейнер ничего не устанавливается.

## Возможности

- Просмотр файловой системы контейнера списком или сеткой, дерево папок, поиск и множественный выбор.
- Управление файлами: создание, переименование, копирование, перемещение, удаление, права, символические ссылки.
- Редактор текстовых файлов и просмотр изображений, аудио, видео, PDF и Markdown.
- Загрузка и скачивание файлов и папок с прогрессом и отменой.
- Работа с архивами (zip, 7z, tar, rar и другие): просмотр, распаковка, добавление файлов и удаление записей без распаковки.
- Монтирования контейнера с пометкой режимов «чтение и запись» и «только чтение».
- Несколько контейнеров рядом, перетаскивание и копирование файлов между ними и с вашего компьютера (Termix Desktop, Проводник и Finder).
- Терминал в контейнере.
- Английский и русский языки.

## Установка

Откройте раздел Plugins в Termix, включите community-реестр (нужны права администратора), найдите Container Files и установите. Затем откройте вкладку Container Files на хосте с включённым SSH.

Подробности, включая то, что разрешено плагину и зачем, в [инструкции](docs/index.ru.md).

## Ограничения

- Пользователь на хосте должен иметь право запускать `docker` или `podman`.
- В остановленных контейнерах и контейнерах без оболочки доступны только просмотр, чтение, загрузка и скачивание; действия, которым нужна оболочка, отключены с указанием причины.
- Архивам нужна своя программа в контейнере (unzip или zip, 7z, tar, gzip, bzip2, xz, zstd, unrar). Rar и одиночные сжатые файлы только для чтения, а для изменения tar-архивов нужен GNU tar. Если программы нет, показывается причина.
- Передачи нельзя возобновить.
